장고로 우리 반 간식 투표 앱 만들기

어려운 말은 최대한 쉽게 바꿨어요. 순서대로 따라 하면 30분 만에 내 컴퓨터에서 돌아가는 웹사이트가 생깁니다. 다 만든 코드는 제가 직접 실행해서 테스트까지 통과한 것이에요.

장고가 뭐예요?

장고(Django)는 웹사이트를 만드는 도구 상자예요. 웹사이트에 꼭 필요한 것들(주소 나누기, 데이터 저장, 로그인, 관리자 화면)이 미리 만들어져 있어서, 우리는 "내 서비스만의 부분"만 만들면 돼요.

장고는 식당이랑 아주 비슷해요. 아래 "주문해 보기"를 눌러 보세요.

🙋손님브라우저
🧑‍💼안내원urls.py
🧑‍🍳요리사views.py
🧊냉장고models.py + DB
🍽️접시templates/*.html
손님이 식당 문을 열고 들어오기 전이에요.
💡

그래서 장고 공부는 결국 "안내원(urls) → 요리사(views) → 냉장고(models) → 접시(templates)" 네 사람이 각자 무슨 일을 하는지 아는 거예요. 교재에서는 이걸 MTV(Model · Template · View)라고 불러요.

Streamlit이랑 뭐가 달라요?

Streamlit은 파이썬 파일 하나를 위에서 아래로 쭉 실행해서 화면을 그려요. 버튼을 누르면 파일 전체가 처음부터 다시 실행되죠. 혼자 쓰는 데이터 대시보드에 딱이에요.

장고는 주소마다 담당 함수가 따로 있어요. 손님이 /로 오면 목록 함수, /vote/3/로 오면 투표 함수가 일해요. 여러 사람이 동시에 쓰고, 로그인하고, 데이터를 오래 저장하는 진짜 서비스에 맞아요.

Streamlit에서는장고에서는한마디로
streamlit run app.pyuv run python manage.py runserver서버 켜기
파일 하나 = 앱 하나프로젝트 하나 안에 앱 여러 개방이 여러 개인 집
pages/ 폴더로 페이지 나누기urls.py에 주소 → 함수 연결안내원
st.write(), st.markdown()템플릿 HTML의 {{ 값 }}접시에 담기
st.text_input()forms.py의 폼 + {{ form.as_p }}주문서
if st.button("투표"):<form method="post"> + 뷰에서 request.method == "POST""이 버튼 눌렀어요!" 쪽지
st.session_staterequest.session (한 사람 기억) / DB (모두의 기억)메모장
CSV·리스트에 저장models.py + DB, ORM으로 저장냉장고
st.dataframe()로 데이터 보기/admin/ 관리자 화면 (코드 3줄)공짜 관리 화면
로그인 직접 구현기본 제공 (django.contrib.auth)현관 잠금장치 기본
Streamlit을 잘 쓰는 사람에게 좋은 소식: 장고의 /admin/은 거의 "공짜 Streamlit 대시보드"예요. 모델만 만들면 데이터 추가·수정·검색 화면이 자동으로 생겨요(5단계에서 해 봐요).

집 짓기: 프로젝트 만들기

먼저 빈 땅(폴더)을 만들고, 장고를 설치하고, 집의 뼈대(프로젝트)를 세워요.

PowerShell
cd C:\sk-encore\app_workspace
uv init snackvote --python 3.12
cd snackvote
uv add "django==5.2.7"
uv run django-admin startproject config .
Remove-Item main.py
왜 그래요? uv init은 땅에 말뚝 박기, uv add는 도구 상자 사 오기, startproject config .는 뼈대 세우기예요. 맨 끝 점(.)은 "지금 이 폴더에 바로 지어 줘"라는 뜻이에요. 점을 빼면 폴더가 한 겹 더 생겨서 헷갈려요.

이제 이런 파일들이 생겼어요.

snackvote/
├── manage.py          # 장고 명령을 내리는 리모컨
├── config/
│   ├── settings.py    # 집 설정 (어떤 방이 있는지, 언어, 시간대…)
│   └── urls.py        # 현관 안내원
└── pyproject.toml     # 장보기 목록

냉장고 설계: 모델 만들기

간식 하나에는 이름과 투표 수가 있어요. 이걸 파이썬 클래스로 적으면 장고가 DB 표(테이블)를 만들어 줘요.

snacks/models.py
from django.db import models


class Snack(models.Model):
    name = models.CharField("간식 이름", max_length=50, unique=True)   # 글자, 50자까지, 중복 안 됨
    votes = models.PositiveIntegerField("투표 수", default=0)          # 0 이상의 숫자, 처음엔 0

    def __str__(self):
        return self.name                                              # 관리자 화면에 이름으로 보이게
PowerShell
uv run python manage.py makemigrations snacks   # 설계도 그리기
uv run python manage.py migrate                  # 설계도대로 냉장고에 칸 만들기
왜 두 번이에요? makemigrations는 "이렇게 바꿀 거예요"라는 설계도 파일을 만들고(snacks/migrations/0001_initial.py), migrate가 진짜로 DB를 바꿔요. 모델을 고칠 때마다 이 두 줄을 다시 실행하면 돼요.

요리사와 안내원: 뷰 + 주소

요리사(뷰)는 냉장고에서 간식을 꺼내 접시(템플릿)에 담아요.

snacks/views.py
from django.shortcuts import render
from .models import Snack


def snack_list(request):
    snacks = Snack.objects.order_by("-votes", "name")    # 투표 많은 순, 같으면 이름순
    return render(request, "snacks/snack_list.html", {"snacks": snacks})

안내원(urls)은 "이 주소로 오면 이 요리사한테 가세요"를 알려 줘요. 방 안에 안내판을 하나 만들고, 현관 안내원에게 연결해요.

snacks/urls.py (새 파일)
from django.urls import path
from . import views

urlpatterns = [
    path("", views.snack_list, name="snack_list"),
]
config/urls.py
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('snacks.urls')),      # 나머지 주소는 간식 방 안내판으로
]
왜 그래요? Snack.objects.order_by(...)가 ORM이에요. SQL을 몰라도 파이썬으로 "냉장고에서 꺼내 줘"라고 말하는 방법이에요. "-votes"의 빼기(-)는 "큰 것부터"라는 뜻이에요.

폴더 이름이 중요해요: snacks/templates/snacks/snack_list.html (snacks가 두 번 들어가요).

snacks/templates/snacks/snack_list.html
<!doctype html>
<html lang="ko">
<head><meta charset="utf-8"><title>우리 반 간식 투표</title></head>
<body>
  <h1>🍪 우리 반 간식 투표</h1>
  <ul>
    {% for snack in snacks %}
      <li>{{ snack.name }} : {{ snack.votes }}표</li>
    {% empty %}
      <li>아직 간식이 없어요.</li>
    {% endfor %}

두 가지 괄호만 기억하세요. {{ }}는 값을 보여 줘(Streamlit의 st.write), {% %}는 반복·조건 같은 명령(파이썬의 for, if). {% empty %}는 "목록이 비었을 때"예요.

투표 버튼 달기

Streamlit이었다면 if st.button("투표"): ... 한 줄이죠. 장고에서는 버튼 = 쪽지 보내기(POST)예요. 쪽지를 받을 요리사를 하나 더 만들어요.

snacks/views.py (아래에 추가)
from django.db.models import F
from django.shortcuts import redirect


def vote(request, pk):
    if request.method == "POST":                                 # 버튼으로 온 쪽지일 때만
        Snack.objects.filter(pk=pk).update(votes=F("votes") + 1)  # DB 안에서 +1
    return redirect("snack_list")                                 # 다시 목록으로
snacks/urls.py
urlpatterns = [
    path("", views.snack_list, name="snack_list"),
    path("vote/<int:pk>/", views.vote, name="vote"),     # /vote/3/ → 3번 간식에 투표
]
snack_list.html 의 <li> 부분
<li>
  {{ snack.name }} : {{ snack.votes }}표
  <form method="post" action="{% url 'vote' snack.pk %}" style="display:inline">
    {% csrf_token %}
    <button>👍 투표</button>
  </form>
</li>
궁금한 것 3개
· <int:pk>: 주소 속 숫자를 꺼내서 함수에 pk로 넘겨 줘요.
· {% csrf_token %}: "이 쪽지는 진짜 우리 사이트에서 보낸 거예요" 도장이에요. 빠지면 403 CSRF 에러가 나요.
· F("votes") + 1: 두 명이 동시에 눌러도 표가 안 사라지게 DB가 직접 더해요.

    간식 추가 폼 만들기

    관리자가 아니어도 화면에서 간식을 추가할 수 있게 해요. 장고는 모델을 보고 입력칸을 자동으로 만들어 줘요(ModelForm).

    snacks/forms.py (새 파일)
    from django import forms
from .models import Snack


class SnackForm(forms.ModelForm):
    class Meta:
        model = Snack
        fields = ["name"]          # 이름 칸만 보여 주기
    snacks/views.py 의 snack_list 를 바꾸기
    from .forms import SnackForm


def snack_list(request):
    if request.method == "POST":               # 추가하기 버튼을 눌렀으면
        form = SnackForm(request.POST)
        if form.is_valid():                    # 빈칸·중복 검사 통과하면
            form.save()                        # 냉장고에 저장
            return redirect("snack_list")
    else:
        form = SnackForm()                     # 처음엔 빈 입력칸
    snacks = Snack.objects.order_by("-votes", "name")
    return render(request, "snacks/snack_list.html", {"snacks": snacks, "form": form})
    snack_list.html 의 </ul> 아래
    <h2>새 간식 추가</h2>
<form method="post">
  {% csrf_token %}
  {{ form.as_p }}
  <button>추가하기</button>
</form>
    Streamlit이랑 비교하면: name = st.text_input("간식 이름") + 직접 검사하던 걸, 장고는 {{ form.as_p }} 한 줄로 입력칸을 그리고 form.is_valid()가 빈칸·글자 수·중복(unique=True)까지 검사해 줘요. 같은 이름을 또 넣으면 에러 메시지도 알아서 보여 줘요.

    화면에 나온 말무슨 뜻이에요?이렇게 고쳐요
    TemplateDoesNotExist접시를 못 찾았어요폴더가 snacks/templates/snacks/파일.html인지, INSTALLED_APPS에 'snacks'가 있는지
    no such table: snacks_snack냉장고 칸이 없어요makemigrations → migrate
    403 CSRF verification failed쪽지에 도장이 없어요POST 폼 안에 {% csrf_token %}
    NoReverseMatch그런 이름의 주소가 없어요{% url 'vote' ... %}의 이름과 urls.py의 name=이 같은지
    Page not found (404)안내원이 모르는 주소예요config/urls.py에 include('snacks.urls')가 있는지
    That port is already in use서버가 이미 켜져 있어요다른 창의 서버를 끄거나 runserver 8001
    모델을 고쳤는데 그대로예요설계도를 안 그렸어요모델을 바꿀 때마다 makemigrations → migrate
    에러 화면은 무섭게 생겼지만 맨 위 제목 한 줄과 노란색으로 칠해진 내 파일 줄만 보면 대부분 답이 나와요. 장고 에러 화면은 DEBUG = True일 때만 보이고, 실제 서비스에서는 꺼야 해요.

    최종 프로젝트로 키우기

    간식 투표를 만들었다면 장고의 뼈대는 다 써 본 거예요. 최종 프로젝트는 이 순서로 넓히면 돼요. (괄호 안은 수업에서 실제로 해 본 장이에요)
