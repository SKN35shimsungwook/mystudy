회귀와 분류, 뭐가 다를까요?

머신러닝이 하는 일은 사실 딱 두 가지예요. 숫자를 맞히거나, 카테고리(종류)를 맞히거나. 이 둘을 각각 회귀(Regression)와 분류(Classification)라고 불러요.

📈

회귀 (Regression)

정답이 연속적인 숫자인 문제예요. "얼마나?", "몇 점?", "얼마짜리?"를 예측해요.

🍎 비유: 나무에 달린 사과들을 보고 "내년엔 사과가 몇 kg 열릴까?"를 숫자로 맞히는 것

예시: 공부 시간으로 시험 점수 예측, 평수로 집값 예측, 키로 몸무게 예측

🐶🐱

분류 (Classification)

정답이 정해진 카테고리 중 하나인 문제예요. "이건 뭐야?", "맞아 틀려?"를 고르는 거예요.

🍎 비유: 과일 바구니를 보고 "이건 사과야, 배야?"를 종류로 맞히는 것

예시: 사진 속 동물이 강아지인지 고양이인지, 이메일이 스팸인지 아닌지, 종양이 악성인지 양성인지

💡 기억하는 방법: 답을 숫자 눈금자로 잴 수 있으면 회귀, 답을 이름표로 붙일 수 있으면 분류예요!

이 노트로 무엇을 할 수 있나요?

데이터 분석의 전체 흐름 — 데이터 수집 → Pandas 기초 → 전처리 → 표 재구성 → 시각화 → 회귀·분류 → 특징 선택을 한 페이지에서 연습해요. 각 주제마다 📖 개념 카드(쉬운 비유 + 진짜 수식)와 🧪 코드 연습(빈칸 채우기)이 함께 있어요.

  • 🌐 데이터 수집 — API 호출과 웹 크롤링(BeautifulSoup)의 핵심 코드를 채워봐요.
  • 🐼 Pandas 기초 — Series·DataFrame, loc/iloc 등 표 다루기의 기본기.
  • 🧹 데이터 전처리 — 결측치 처리, 구간분할, 인코딩, 스케일링.
  • 🔀 데이터프레임 응용 — merge/concat/join, pivot/melt, groupby.
  • 📊 시각화 — matplotlib과 seaborn으로 그래프 그리기.
  • 📈 회귀 놀이터 — 슬라이더로 직접 선을 그어보며 오차(MSE)가 어떻게 줄어드는지 체험해요.
  • 🐾 분류 놀이터 — 강아지·고양이 카드를 직접 맞혀보며 혼동행렬과 정확도·정밀도·재현율을 만들어봐요.
  • 🧬 특징선택·차원축소 — 변수를 줄이는 두 가지 방법과 PCA.
  • 📖 용어 사전 — MAE부터 F1-score까지, 카드를 뒤집으면 쉬운 설명과 진짜 수식이 함께 나와요.

📈 회귀 놀이터 — 점들에 가장 가까운 선 찾기

아래는 "공부 시간"과 "시험 점수"를 기록한 점들이에요. 여러분이 기울기(W)와 절편(b)을 움직여서, 점들에 가장 가까운 직선을 찾아보세요. 이게 바로 선형회귀(Linear Regression)예요!

0 MSE (평균제곱오차)
0에 가까울수록 좋아요
아직 더 맞춰봐요

점선은 각 점과 예측선 사이의 오차(error)예요. 이 오차를 제곱해서 평균 낸 게 바로 MSE! "자동으로 학습시키기"를 누르면, 경사하강법(gradient descent)이 오차가 가장 작아지는 방향으로 선을 조금씩 움직여요.
👩‍💻 진짜 파이썬 코드는 이렇게 생겼어요
# scikit-learn으로 회귀 모델 학습하기 from sklearn.linear_model import LinearRegression from sklearn.metrics import mean_squared_error, r2_score model = LinearRegression() model.fit(X_train, y_train) # 선 긋는 연습(학습) y_pred = model.predict(X_test) # 새 데이터로 예측 mse = mean_squared_error(y_test, y_pred) # 놀이터의 MSE와 같은 것! r2 = r2_score(y_test, y_pred) # 1에 가까울수록 잘 맞춘 것
