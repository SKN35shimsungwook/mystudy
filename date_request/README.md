# 💌 데이트 신청서

핑크 & 하트 테마의 귀여운 데이트 신청 Streamlit 앱.

## 흐름

1. **신청** — "나랑 데이트 할래?" `좋아 💖` / `거절 🙅`
   - 거절 버튼은 마우스를 올리거나 터치하면 **도망갑니다** (클릭 불가)
   - 도망칠 때마다 놀리는 멘트가 나오고 `좋아` 버튼이 점점 커짐
2. **날짜** — 달력 + 시간대(아침/점심/오후/저녁/밤) 또는 `⏰ 직접 정하기`로 10분 단위 시간 선택
3. **밥** — 한식·일식·양식·중식·고기·분식 카드 중 하나, 또는 직접 입력(예: 마라탕)
4. **장소** — 카페·영화·산책·전시회 등 여러 개 선택 + 직접 추가(예: 한강 피크닉)
5. **디저트** — 디저트 하나(직접 추가 가능) + 하고 싶은 말
   - 직접 입력한 항목은 `✏️`가 붙고, `추가` 버튼이나 엔터로 바로 선택됨
6. **완성** — 풍선 🎈 + 데이트 확인서, `.txt` 다운로드

## 실행

```bash
cd date_request
pip install -r requirements.txt
streamlit run app.py
```

> 핑크 테마(`.streamlit/config.toml`)는 `date_request` 폴더 안에서 실행해야 적용됩니다.

## 구조

| 파일 | 설명 |
| --- | --- |
| `app.py` | 전체 앱. 선택지(`FOODS`, `PLACES`, `DESSERTS` 등)는 파일 상단에서 수정 |
| `.streamlit/config.toml` | 핑크 테마 색상 |

- 페이지 전환: `st.session_state.step` (0~5)
- 도망가는 버튼: `st.components.v2.component` (HTML/CSS/JS). `좋아` 클릭은 `setTriggerValue`로 파이썬에 전달
- 선택값은 위젯 `key`로 session_state에 저장되고, 페이지를 넘겨도 유지되도록 매 실행마다 다시 대입
