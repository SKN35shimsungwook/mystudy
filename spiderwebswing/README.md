# 🕸️ 스파이더멘 웹스윙 3D (Streamlit 버전)

이 폴더는 [스파이더멘 웹스윙 3D 게임](https://github.com/SKN35shimsungwook/spider)을
**Streamlit**이라는 도구로 감싸서, 파이썬 프로젝트처럼 배포할 수 있게 만든 버전이에요.

## 1. 이건 원래 버전이랑 뭐가 달라요?

게임 자체(거미줄 쏘고, 벽 타고, 싸우는 것)는 **완전히 똑같아요.** 달라지는 건 딱 하나,
**"이 게임을 어떤 그릇에 담아서 보여주냐"** 예요.

비유하자면 이런 거예요:

- **원본 버전** (`github.com/SKN35shimsungwook/spider`) → 게임이 **혼자 사는 집** 이에요. 게임 파일 하나가 전체 페이지를 다 차지해요.
- **이 버전** (`spiderwebswing/`) → 게임을 **액자에 넣어서**, "스트림릿"이라는 큰 방(파이썬 웹앱) 안에 걸어둔 거예요. 방 안에는 게임 제목, 설명, 조작법 같은 파이썬으로 만든 다른 것들도 같이 있어요.

## 2. 왜 굳이 이렇게 만들었어요?

이 프로젝트를 만든 분이 평소에 **"파이썬으로 만들고 → Streamlit으로 배포하기"** 라는 방식을 자주 쓰시기 때문이에요.
그래서 다른 파이썬 프로젝트들(예: `baseballhomerun/`)과 **같은 방식**으로 이 게임도 배포할 수 있게 만든 거예요.

다만 한 가지 중요한 점이 있어요: 이 게임은 **1초에 60번씩 움직임을 계산**해야 하고, **키보드/마우스를 실시간으로** 받아야 하는 액션 게임이에요.
그런데 Streamlit은 원래 "버튼을 누르면 파이썬 코드를 처음부터 다시 실행하는" 방식이라, 이런 빠른 액션 게임을 파이썬 코드로 직접 다시 만들 수는 없어요.

그래서 택한 방법이: **게임은 원래 그대로(HTML/JavaScript) 두고, 그 게임 전체를 통째로 Streamlit 페이지 안에 "끼워 넣기"** 예요.
그럼 게임의 움직임과 손맛은 원본이랑 똑같이 유지되면서, 배포만 Streamlit 방식으로 할 수 있어요.

## 3. 기술 스택 (쉽게 설명)

| 기술 | 무슨 역할? |
|---|---|
| **Streamlit** | 파이썬 코드만으로 웹페이지(제목, 설명, 버튼 등)를 뚝딱 만들어주는 도구예요. |
| **`st.components.v1.html()`** | Streamlit 페이지 안에 **다른 웹페이지를 통째로 넣을 수 있는 작은 창문(iframe)** 을 만드는 명령이에요. 이 창문 안에 `game.html`(원본 게임)을 그대로 띄워요. |
| **`game.html`** | 진짜 게임 본체예요. Three.js, WebGL 같은 기술로 만들어졌고, `spider` 저장소에 있는 것과 완전히 똑같은 파일이에요. |

즉, **파이썬(Streamlit)은 게임을 담는 "액자"만 만들고, 게임 자체는 그 안에서 원래 방식(JavaScript) 그대로 돌아가요.**

## 4. 내 컴퓨터에서 직접 실행해보기

```bash
pip install -r requirements.txt
streamlit run main.py
```

실행하면 브라우저가 자동으로 열리면서 게임이 있는 페이지가 나와요.

## 5. 파일 구성

```
spiderwebswing/
├── main.py           # Streamlit 페이지 (제목, 설명, 게임을 끼워 넣는 코드)
├── game.html          # 진짜 게임 본체 (원본과 동일)
└── requirements.txt   # 필요한 파이썬 패키지 목록 (streamlit 하나뿐)
```

## 6. 그냥 게임만 바로 하고 싶다면?

Streamlit 없이 원본 그대로 바로 플레이하려면 ▶ **[여기](https://skn35shimsungwook.github.io/spider/)** 를 누르세요.
