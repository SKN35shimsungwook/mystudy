# 🏎️ 휠 액셀 레이싱 (Streamlit 버전)

이 폴더는 [휠 액셀 레이싱](../휠액셀카레이싱.html) 게임을 **Streamlit**이라는 도구로 감싸서,
파이썬 프로젝트처럼 배포할 수 있게 만든 버전이에요. `main.ipynb` 노트북 하나만 열어서 위에서부터
순서대로 실행하면 `game.html` / `main.py` / `requirements.txt`가 전부 자동으로 생성돼요.

## 1. 이건 원래 버전이랑 뭐가 달라요?

게임 자체(휠로 가속하고, WASD로 조향하고, Space로 드리프트하는 것)는 **완전히 똑같아요.**
달라지는 건 딱 하나, **"이 게임을 어떤 그릇에 담아서 보여주냐"** 예요.

- **원본 파일** (`휠액셀카레이싱.html`) → 게임이 **혼자 사는 집**이에요. HTML 파일 하나가 전체 페이지를 다 차지해요.
- **이 버전** (`wheelaccelracing/`) → 게임을 **액자에 넣어서**, "스트림릿"이라는 큰 방(파이썬 웹앱) 안에 걸어둔 거예요. 방 안에는 게임 제목, 설명, 조작법 같은 파이썬으로 만든 다른 것들도 같이 있어요.

## 2. 왜 굳이 이렇게 만들었어요?

이 프로젝트를 만든 분이 평소에 **"파이썬으로 만들고 → Streamlit으로 배포하기"** 라는 방식을 자주 쓰기 때문이에요.
그래서 다른 파이썬 프로젝트들(예: `spiderwebswing/`, `baseballhomerun/`)과 **같은 방식**으로 이 게임도 배포할 수 있게 만든 거예요.

다만 한 가지 중요한 점이 있어요: 이 게임은 **1초에 수십 번씩 물리 연산(가속·드리프트·충돌)을 계산**해야 하고,
**마우스 휠과 키보드를 실시간으로** 받아야 하는 액션 게임이에요. 그런데 Streamlit은 원래
"버튼을 누르면 파이썬 코드를 처음부터 다시 실행하는" 방식이라, 이런 빠른 액션 게임을 파이썬 코드로
직접 다시 만들 수는 없어요.

그래서 택한 방법이: **게임은 원래 그대로(HTML/JavaScript) 두고, 그 게임 전체를 통째로 Streamlit 페이지
안에 "끼워 넣기"** 예요. 그럼 게임의 움직임과 손맛은 원본이랑 똑같이 유지되면서, 배포만 Streamlit
방식으로 할 수 있어요.

## 3. `main.ipynb`는 왜 있어요?

이 워크스페이스는 같은 코드를 `.py`와 `.ipynb` 두 형태로 같이 관리하는 습관이 있어요
(`ml_study_playground.py` / `.ipynb`처럼요). `main.ipynb`를 열어서 셀을 위에서부터 순서대로 실행하면:

1. `game.html` — 게임 본체
2. `main.py` — Streamlit 페이지
3. `requirements.txt` — 의존성 목록

세 파일이 이 폴더 안에 그대로 생성(또는 최신 내용으로 덮어쓰기)돼요. 즉 `main.ipynb`가 이 폴더의
**소스**이고, 나머지 세 파일은 그 소스로부터 만들어지는 결과물이에요. 이미 세 파일이 있는 상태에서
노트북을 다시 실행해도 내용이 동일하게 갱신될 뿐이라 안전해요.

## 4. 기술 스택 (쉽게 설명)

| 기술 | 무슨 역할? |
|---|---|
| **Streamlit** | 파이썬 코드만으로 웹페이지(제목, 설명, 조작법 등)를 뚝딱 만들어주는 도구예요. |
| **`st.components.v1.html()`** | Streamlit 페이지 안에 **다른 웹페이지를 통째로 넣을 수 있는 작은 창문(iframe)** 을 만드는 명령이에요. 이 창문 안에 `game.html`(원본 게임)을 그대로 띄워요. |
| **`game.html`** | 진짜 게임 본체예요. HTML5 Canvas와 순수 JavaScript로 만든 탑다운 드리프트 레이싱 게임이에요. |

즉, **파이썬(Streamlit)은 게임을 담는 "액자"만 만들고, 게임 자체는 그 안에서 원래 방식(JavaScript) 그대로 돌아가요.**

## 5. 내 컴퓨터에서 직접 실행해보기

```bash
# 1) (선택) 노트북을 실행해서 game.html / main.py / requirements.txt를 생성·갱신
jupyter nbconvert --to notebook --execute --inplace main.ipynb

# 2) 패키지 설치 후 실행
pip install -r requirements.txt
streamlit run main.py
```

이미 `main.py`와 `game.html`이 폴더에 들어있으니, 노트북을 다시 실행하지 않고 바로
`streamlit run main.py`만 해도 게임이 실행돼요.

## 6. 파일 구성

```
wheelaccelracing/
├── main.ipynb         # 소스 노트북 — 실행하면 아래 3개 파일을 생성/갱신함
├── main.py             # Streamlit 페이지 (제목, 설명, 게임을 끼워 넣는 코드)
├── game.html            # 진짜 게임 본체 (Canvas + JS, 원본과 동일)
└── requirements.txt     # 필요한 파이썬 패키지 목록 (streamlit 하나뿐)
```

## 7. 조작법

- **마우스 휠 위로 굴리기** : 가속 · **아래로 굴리기** : 브레이크/후진
- **A / D** : 좌우 조향, **W / S** : 보조 가속/브레이크
- **Space** : 핸드브레이크(드리프트) — 콤보를 쌓았다가 떼면 부스트
- **R** : 재시작 · 3랩 완주 시 총 기록과 베스트 랩 표시

## 8. 그냥 게임만 바로 하고 싶다면?

Streamlit 없이 원본 그대로 바로 플레이하려면 프로젝트 루트의
[`휠액셀카레이싱.html`](../휠액셀카레이싱.html) 파일을 브라우저로 열면 돼요.
